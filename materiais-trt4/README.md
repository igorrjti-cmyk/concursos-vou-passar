# Materiais de estudo — TRT-4

Adicione os PDFs do concurso nas pastas de cada disciplina:

- `teoria/`: apostilas, resumos, legislação e materiais teóricos.
- `provas/`: provas anteriores, cadernos de questões e gabaritos.

Prefira nomes claros, por exemplo `fcc-2024-prova.pdf` ou `direito-administrativo-poderes.pdf`. Não misture disciplinas. Se um PDF tiver várias disciplinas, prefira separá-lo antes do envio. Os arquivos enviados aqui serão usados para organização e estudo; questões antigas não serão consideradas automaticamente questões oficiais do TRT-4.
